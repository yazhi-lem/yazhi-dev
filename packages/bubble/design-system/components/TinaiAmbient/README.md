# TinaiAmbient

The living background of a tiṇai: one canvas of hairlines that answers the pointer the way its landscape would — dune contours bend like heat haze (Palai), fireflies drift and keep their distance (Mullai), mist parts (Kurinji), seedlings bow to the wind (Marutham), tide lines breathe and take ripples (Neytal).

**The consumer provides** `tinai`. Place it inside the matching TinaiScope. Drawn in the scope's own `--env-*` ink so it cross-fades with the page; it never takes the pointer, sleeps offscreen and in hidden tabs, draws one still frame under reduced motion, and is `aria-hidden`.

No preview here: it is a canvas animation. Source: `packages/bubble/src/tinai/TinaiAmbient.tsx`.
