# MarkBubble

The Yazhi mark — three bubbles, L : M : S = 1.00 : 0.74 : 0.56, never touching — held inside one bubble. It is Mission Control's face.

**The consumer provides** `size` (px, default 40), `awake` (default true), `className`. Awake, the marks fill with `ivory` inside a `gold` ring on a 14% `gold` wash; asleep (no Circle account yet) they are open `ivory-dim` rings on a dashed bubble.

Purely drawn: the button that carries it supplies the name. Never change the ratio or close the gaps. Source: `packages/bubble/src/mission/MarkBubble.tsx`.
