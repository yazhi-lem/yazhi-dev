# HintLadder

Guru's tutoring pattern: hints revealed one rung at a time, never the answer. The last rung hands the work back to the student (a `mullai` note).

**The consumer provides** `prompt`, `hints` (in order), and `handBack` — what the student does after the last hint. Dress it in Mullai (`TinaiScope tinai="mullai"`) so `accent` is the Keeper's green.

Never include the answer in `hints`. Source: `packages/bubble/src/modules/HintLadder.tsx`.
