# ThinaiThemes

The five Sangam landscapes as five pastel themes of one identical layout: only `tn-surface`, `tn-tint`, `tn-tint-strong`, `tn-ink` and `tn-ink-muted` change; go, stop, spacing, radii and type never do.

Switch with `data-theme="light" data-tn="kurinji|mullai|marutham|neithal|paalai"` on the shell; High contrast is `data-tn="contrast"`, Night is `data-theme="dark"`. Mullai is the default.

| Thiṇai | Landscape | Pastel | Suits |
| --- | --- | --- | --- |
| குறிஞ்சி Kurinji | hills, the kurinji bloom | lavender `tn-kurinji` | bedtime, calm stories |
| முல்லை Mullai | forest, jasmine | mint `tn-mullai` | home, the default |
| மருதம் Marutham | paddy fields | butter `tn-marutham` | learning, questions |
| நெய்தல் Neithal | seashore | sky `tn-neithal` | songs, sound |
| பாலை Paalai | dry land | peach `tn-paalai` | games, challenges |

One thiṇai per screen; a child changes landscape when they change place in the app, never mid-task.
