# Icons

The full Yazhi Thiṇai icon set at 32px, with the seven theme marks on their own colours. See the Icons asset group for the upload-ready SVGs.

Inline an icon as `<svg class="yz-ico" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">…paths…</svg>`. It takes the colour of the text around it, so it passes contrast wherever that text does.

Where icons go:
- the start of every nav item
- after a green button's word, and before a red button's word
- the start of every notice
- the start of every settings row and group heading
- inside citation chips and verified marks
