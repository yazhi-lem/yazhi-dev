# Trust

`FivePostureTrace` shows one turn through the Five-Posture Reasoning Kernel; `ConsentGate` is Yazh's admission gate, shown to the parent.

**FivePostureTrace** — `results` (`PostureResult`: `posture` context·reason·plan·respond·reflect, `pass`, `note`). Passes are `mullai` ✓, failures `palai` ✕; the header pill counts failures. Failures become training pairs.

**ConsentGate** — `verified`, `children`, `onStart`. Nothing behind it renders until consent is verified — a server-side check; this component only reflects it. Aram rule 4: children first.

Source: `packages/bubble/src/modules/Trust.tsx`.
