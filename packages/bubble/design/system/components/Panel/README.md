# Panel

The raised surface every module sits on — `night-2` at 80%, a 10% `ivory` hairline, an optional header — and `EmptyState` for a view with nothing in it yet.

**Panel** — `children`; optional `title`, `eyebrow` (set in `accent`, 11px), `actions` (right of the header, usually Pills), `className`, and `accentEdge` — a 2px left edge in `accent` for the **one** primary panel on a page.

**EmptyState** — `title`, optional `hint` and `action`. A dashed 15% `ivory` border, centred.

Source: `packages/bubble/src/components/Panel.tsx`.
