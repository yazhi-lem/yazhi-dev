### 6.3 Would break `npm run build`

1. Font network fetch — 4 Google faces `layout.tsx:19,24,28,34`; a 5th raises offline failure odds (§2).
2. `server-only` reachable from a client component (§6.2).
3. `localStorage` in render — safe today (`src/lib/i18n.tsx:18-21`, `packages/workspace/src/store.ts:33` use `useEffect`); a new `useLocale()` reading it during render → prerender error.
4. `<html lang>` mismatch: `layout.tsx:72` static `"ta"`; any other locale default breaks prerender/hydration parity.
5. Duplicate root layouts if a `[locale]` segment is added (§5).
6. Turbopack + `next/font` — already burned once (`layout.tsx:39-41`).
7. `eslint` is a separate script (`package.json` `scripts.lint`) — an `i18n:check` failure will **not** fail `build` unless wired in.
8. Only `api/circle/_shared.ts:18` sets `Cache-Control`; A2's `force-dynamic` routes must set it themselves.
