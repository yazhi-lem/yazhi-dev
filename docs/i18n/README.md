# docs/i18n/

Status: current · Owner: Vajra (site/docs) · Verified: 2026-11-21 against `main`

Generated and review material for the site's three languages (Tamil, English,
Hindi).

| File | What it is | Regenerate with |
|---|---|---|
| `CATALOGUE.json` | The catalogue skeleton: every key found in source, with counts per catalogue | `npm run i18n:extract` |

Check the catalogue in CI or before a release with `npm run i18n:check`.

The machine-drafted Hindi review lives in
[`../../archives/2026-11-09-hindi-machine-review.md`](../../archives/2026-11-09-hindi-machine-review.md)
and is regenerated by `scripts/gen-hindi-review.mjs`. It is a review aid, not
published copy; Hindi stays `reviewRequired` until a native speaker signs each
line off.

The string sources are in `src/lib/content.ts` (site copy),
`packages/i18n/src/` (site chrome and the language switcher) and
`packages/bubble/src/locales/` (the Bubble UI library's own copy).
