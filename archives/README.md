# archives/

Dated, never-edited snapshots of this repo's docs. [`2026-10-27-docs-digest.md`](2026-10-27-docs-digest.md) maps
the docs that remain, lists where they disagree, and holds compressed copies of every doc retired that day. To retire
a doc: add its compressed copy to a new dated digest, delete it, and fix inbound links. Live plans live in
[`../factory/`](../factory). Full text of retired docs: git history.

Also here: [`2026-10-18-tamil-rewrite-log.json`](2026-10-18-tamil-rewrite-log.json), the per-string record of the AI
Tamil rewrite of the main site (key, location, before, after), kept for the native-speaker sign-off. The v1
cyberpunk site (`previous-designs/`) was removed on 27 Oct; restore it from git history (last present at the commit
before this cleanup).
